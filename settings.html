语音 · 音色

课件讲解支持中文（普通话）和英文。下面可以分别选择中文音色和英文音色，选择后所有课件都会用你选的声音讲解。

🌐 在线音色（无需系统语音，pad / 手机通用）

系统检测不到音色（常见于 Android pad）时，选这里的音色即可正常朗读。在线音色通过微软免费朗读服务生成，需要联网，不依赖设备 TTS 引擎。

说明

· 系统音色来自设备自带的语音能力；若检测不到（Android pad 常见），直接用上方「🌐 在线音色」即可，无需装任何语音。

· Android pad 提示：若想用系统音色，可到「设置 → 辅助功能 → 文字转语音(TTS)输出」启用 TTS 引擎并下载「中文（普通话）」语音数据，然后点「重新检测音色」；Chrome/Edge 在 Android 上对系统语音支持有限，用「在线音色」最省事。

· Windows 到「设置 → 时间和语言 → 语音」、macOS 到「系统设置 → 辅助功能 → 朗读内容」里添加中文/英文语音。

· 在线音色需要联网，首次选择后点「试听」确认能出声。
